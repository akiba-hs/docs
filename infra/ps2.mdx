# PS2

## Гайд по запуску PS2

1. включаете PS2 (без диска!)
2. заходите в браузер (большими английскими буквами "browser" написано)
3. заходите на карту памяти (просто открываете ее, дальше щёлкать по файлам на ней не надо)
4. выходите из карты памяти на главный экран (два раза нолик).

//p.s.
